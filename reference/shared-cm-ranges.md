Use this table to list which relationships a shared-cM value is consistent with. The range is the observed range from the Shared cM Project's submissions, not a hard limit. Distant cousins can share 0 cM. Values are autosomal cM as reported by the testing company; companies differ slightly.

## How to use it

**Example.** A match shares 1,102 cM with the tester. Relationships whose range includes 1,102: half sibling (1160–2436) does *not*; aunt/uncle (1201–2282) does *not*; grandparent (984–2462) does; great-grandparent (485–1486) does; half aunt/uncle (492–1315) does; great-aunt/uncle (330–1467) does; first cousin (396–1397) does. So the honest statement is: "1,102 cM is consistent with a grandparent, a first cousin, a half aunt or uncle, a great-aunt or uncle, or a great-grandparent. It is below the observed range for a half sibling." Ages and the documented tree narrow it from there.

**Percentages.** 23andMe shows percent shared. Multiply by roughly 74 to estimate cM (100% is about 7,400 cM on 23andMe's scale), or ask the participant whether the site also shows cM.

**Endogamy.** In endogamous populations, treat every range as shifted upward and every "close" match as possibly more distant than it looks.
